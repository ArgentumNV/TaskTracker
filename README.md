# TaskManager

Консольный менеджер задач на C++ с поддержкой времени создания и статусов.

## 📋 Возможности

- ✅ Добавление задач с описанием
- ✅ Просмотр всех задач с временем создания
- ✅ Автоматическая генерация ID задач
- ✅ Хранение времени создания и обновления

## 🚀 Установка и сборка

### Требования

- C++17 или выше
- CMake 3.20 или выше
- Компилятор (GCC, Clang или MSVC)

### Сборка

```bash
# Клонирование репозитория
git clone https://github.com/your-username/TaskManager.git
cd TaskManager

# Сборка через CMake
mkdir build && cd build
cmake ..
make

# Запуск
./task_manager
```
